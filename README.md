## Featured project

### [OpenAPI MCP Server](https://github.com/jobyywilson/openapi-mcp-server)

A Java server that turns OpenAPI specifications into MCP tools, enabling AI clients to interact with existing APIs.

- **Stack:** Java 21, Maven, OpenAPI / Swagger, JSON and YAML.
- **Integration:** Dynamic tool generation and stdio transport for MCP clients.
- **Configuration:** Command-line arguments and environment variables.
- **Authentication:** Basic, bearer token, API key and custom headers.

See the repository for build instructions, configuration options and client integration examples.
